# boletim9C

Cópia de estudo do projeto `boletim9C` (base `eaea34501464f52d6991eda1d24a1dd2aeff11b5`). Preserva o visual escuro/verde e os cálculos originais.

Esta versão acessa a API `https://boletim-api.profbt.com.br` apenas para a turma **9C**, chamada **21**. O estudante informa o PIN na página; ele não é exibido, calculado nem guardado em URL ou armazenamento local. Ao abrir um boletim ainda sem dados, a página apresenta uma cópia das 15 disciplinas originais, sem gravá-las até que o estudante clique em salvar. Dados já salvos na API têm precedência total.
